This is a simple website build using HTML,CSS and Javascript.
It is basically a pg management system with a find-your-mate as its highlight
**Find-you-mate** is a feature where we match the details of new joinee with the guest details present in pg and find the best match
here we calculate the match percentage by using the formula total traits match/total number of traits and by using this we find the highest match percentage.
**Findus** is another feature added to this project where we have use openstreetmap to show the distance between the user current location and pg and used leaflet.js to make the map interactive
